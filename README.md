## `list_participating_projects.py`

This script converts a CSV export of project records into a single interactive HTML fragment grouped by major. It is designed to generate content that can be inserted into an existing page shell rather than serve as a standalone HTML site.

### What the script needs

The script expects a CSV file named `projects.csv` in the current working directory when you run it.

It reads these columns from the CSV:

- `Selected Category`
- `Application Name`
- `(Team & Judge Registration - Phase I - Team Registration) Booth Number`
- `(Team & Judge Registration - Phase I - Team Registration) SPONSOR NAME`
- `(Team & Judge Registration - Phase I - Team Registration) PROJECT DESCRIPTION`
- `Applicant First Name`
- `Applicant Last Name`

If any of those columns are missing, the script will fall back to placeholder text such as `N/A` or `No description available.`

### What the script produces

The output file is `interactive_projects_grouped.html`.

The generated file includes:

- the page banner
- the styled project search and filter controls
- grouped major sections
- expandable project cards
- the filtering and sorting JavaScript

### How to run it

From the `EPS-VPS-Project-Showcase` folder:

```powershell
python .\list_participating_projects.py
```

If you want to run it from a different folder, make sure the working directory still contains `projects.csv`, or update the `input_file` path inside the script.

### Important note

This script writes an HTML fragment, not a full standalone HTML page. The generated output is meant to be inserted into the existing showcase layout or copied into the page that will host the project listing. Refer to '2026 EPS Participating Projects' page on the OpenWater website. Copy the code generated by this section and paste it in the Source section

## Working With the Site Files

The HTML files in this repository are split into reusable pieces so the same header, footer, and shared resources can be reused across pages. In practice:

- `head-scripts.html` handles shared external CSS/JS imports.
- `header.html` and `footer.html` hold the reusable page chrome.
- `main.css` contains the site styling.
- `main.html`, `home.html`, `sponsors.html`, and `sponsor-capstone.html` provide page-specific content.

If you are updating the generated projects view, regenerate `interactive_projects_grouped.html` after changing the CSV source data, then paste or insert the new fragment into the destination page.
